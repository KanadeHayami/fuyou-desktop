# v1.0.0 发布验证

当前最新功能统一采用 v1.0.0 编号：离线图鉴、符文与英雄图片、随机事件、机制、自选模拟器、局内 buff 悬停读数、固定悬浮圆钮和私人队友红黑榜。

应用 package.json、锁文件、打包应用及 NSIS 安装包版本一致为 1.0.0。应用标识和用户数据目录保持稳定。旧版 GSI 与背包估算入口仍停用，局内读数需要手动开启。

## 验证结果

- 依赖安装成功；复用现有依赖，不增加或升级依赖。
- 福佑数据构建通过：636 条、267 通用、369 专属、636 图标、118 个相关英雄、0 个未确认名称。
- 类型检查通过；12 个测试文件、64 项单元测试全部通过。
- 应用构建和 Windows x64 NSIS 构建通过。安装包大小 138,287,288 字节。
- 图鉴和模拟器在 1280×800、840×800、400×820、360×480、700×800、1100×800 通过界面回归，无横向溢出或控制台错误。
- 四种尺寸的资料、隐私、符文中文名、图标和局内读数界面专项全部通过；1280 宽度逐项核对 36 条符文、125 位英雄的图片与对应详情。
- 局内专项使用隔离的离线样本，验证开始／暂停、同名记录复核、零值和负值、总值与加成分离、上次读数、清空、固定圆钮和竖向菜单。普通浏览器中采集及悬浮入口禁用。
- 公开源码的构建输出与本地构建、安装包应用内容的 935 个文件逐项 SHA-256 一致。包内包含 636 个福佑图标、36 个符文图标、125 个英雄小图标及 125 个头像；解包 OCR 脚本与源码一致。
- 发布源码及安装包应用内容的密钥扫描通过；未检出已知私密凭据、真实账号标识或私人输入目录。

## 验证边界

原生窗口验收执行时检测到 Dota 2 正在运行，防干扰检查在启动测试窗口之前停止；本轮未完成原生窗口复测。没有停止游戏、执行系统安装／卸载或清空用户记录。

公开源码不包含个人截图、名单、实采记录、开发期私有历史或原始研究资料。普通构建使用已提供的数据与图片；显式重建资料需要按 SPEC 自备输入。
