# 福佑大乱斗小助手实现规格

Windows x64，Electron、Vite、TypeScript、Preact。界面使用简体中文，深色石墨主题；数字为绿色，品质为蓝／紫／橙。支持横版、半屏、400×820 竖版和最小 360×480，窄窗原地展开详情。

## 当前功能

- 图鉴：636 条福佑，品质、通用／专属、英雄与标签筛选，中文／拼音查询、收藏与复制。
- 符文：36 条游戏中文名和已确认的中文参数；侧翼霰弹枪保留资料并标为“已移除”。支持中文、全拼、首字母、原 ID 查询。
- 英雄对照与候选池：125 条英雄、69 个池，113 条英雄有池、12 条未配置；支持双向跳转。机会值和进池判定值保持各自含义。
- 随机事件：21 条，缺失权重显示“—”，与 0 区分。
- 机制：福佑抽取、重随与重铸、符文选择、随机事件、基础玩法；返回保留查询和位置。
- 模拟器：从真实福佑自选搭配，区间中点与范围约束、移速假设、明确规则的部分合计、保存、移除、清空与撤销。
- 队友：手动导入截图、本地 Windows 中文 OCR、玩家核对、号码匹配、红黑榜和备注；记录保存在本机。无后台采集。
- 图标：36 条符文游戏原图、125 位英雄的小图标和选人头像，全部内置，支持离线加载。
- 局内：手动启动的 buff 悬停读数、本地中文 OCR、同名去重与更新；总值、加成和参考门槛分别显示。默认每秒检查，可改两秒，仅处理前台游戏鼠标附近画面，不读内存、不落盘或上传截图。
- 悬浮入口：固定位置圆钮和竖向属性菜单，展开收起保持圆钮位置；支持拖动、关闭和本机位置保存。
- 桌面：默认横版，横竖切换、置顶、窗口控制及筛选／方案持久化。浏览器可独立预览。

## 显示约束

不显示工程路径、资料来源索引、查看来源、日期／版本参考或不确定性提示段落。复制与界面保持一致。保留真实数值、负号、0 和缺失值，不将权重或候选判定值改成最终概率，不编造名称、数值、玩家或实时状态。

## 局内读数边界

完整提示框连续两次一致才入账；同名更新不重复累加，总值与部分加成分开，冲突与上次读数明确标识。换局手动清空，无法自动确认本人身份或区分同名不同来源。未完成长期对局和 FPS 验证。

## 数据构建

仓库附带已生成的 data 和图标，普通构建无需外部输入。显式重建需要自备资料并设置环境变量；源码不包含原始输入目录。

- FUYOU_SOURCE：catalog-manifest.json（id、scope、quality、heroTags、customTags 的数组）、catalog.csv（id、名称、当前描述_代入内存值），以及重建资料时的 raw-blessings.json。
- FUYOU_ICONS：按福佑 ID 命名的 PNG 目录。
- FUYOU_REFERENCE_SOURCE：reference.dataset.json，以及可选 rune-scripts/sl_modifier_<符文ID>.lua、event-scripts/rnd_event_<事件ID>.lua 说明文本。
- FUYOU_HERO_VPK、FUYOU_RUNE_VPK：可选的只读游戏图标输入包；普通构建使用已保存图片。
- FUYOU_LOCALIZATION_SOURCE：key、value 两列的游戏中文 KV 表 CSV；36 条符文提示标题与选择名称必须一致。

数据构建验证福佑 636／267 通用／369 专属、图标完整，资料构建验证 36 符文／69 池／125 英雄／21 事件。输入缺失或不满足断言时失败；普通开发使用已保存数据。

## 验收与打包

npm install；npm run typecheck；npm test；npm run build。启动 npm run dev:web 后执行 test:ui、test:reference、test:privacy、test:localization、test:reference-icons、test:live。原生 test:electron 不在 Dota 2 运行期间执行；测试使用独立临时用户目录。

npm run dist 生成 Windows x64 NSIS 安装包。FUYOU_EXECUTABLE 可指定打包程序执行原生验证。队友数据、个人图片、旧本地开发历史、验收截图不随公开源码分发；发布不清空本机记录。
