# 福佑大乱斗小助手

v1.0.0 · Windows 离线图鉴、福佑模拟器、局内 buff 悬停读数与私人队友红黑榜，包含 636 条福佑、36 条符文、125 条英雄对照、69 个候选池和 21 条随机事件。识别仅在手动开启局内采集或导入队友截图时运行。

每次启动默认横版，右上角点击“竖版”切为窄窗口，再点“横版”恢复。切换保留当前内容；小屏幕自动限制窗口尺寸。浏览器预览的窗口切换按钮禁用。

本版图鉴包含福佑、符文、随机事件三类，并新增独立机制页。全部符文使用游戏中文名，“侧翼霰弹枪”标记为“已移除”。

当前源码增加 36 条符文游戏原图、125 位英雄的小图标与选人头像，显示在符文／英雄对照列表及详情，所有图片内置并支持离线加载。

## 查询新增资料

- 图鉴 → 符文：查询 36 条符文的游戏中文名、效果和中文数值参数，支持中文、拼音及原始英文标识搜索；切到候选池查看 69 组配置，可按英雄名或符文名查询。
- 图鉴 → 符文 → 英雄对照：125 条英雄配置，113 条有池、12 条未配置；支持中文、拼音、英文标识与标签查询。英雄和候选池可以互相跳转，详情保留权重、标签、属性与本命福佑原值。
- 图鉴 → 随机事件：21 条配置，按大于 0、为 0、无权重筛选。缺失权重显示“—”，与 0 分开显示。
- 机制：查看福佑抽取、重随与重铸、符文选择、随机事件、基础玩法。相关规则也可从图鉴和模拟器进入；返回保留查询和位置。

符文名称取自游戏中文文本，例如射手、神射手、法师、大法师。品质占比来自基础权重折算，符文机会值用于进池判定。英雄属性原值未加入模拟器合计。

## 使用模拟器

1. 打开“模拟器”，搜索名称、效果、英雄或拼音，可筛选品质及通用/专属。
2. 点击添加福佑，同一 ID 只添加一次，可同时搭配多条。
3. 已选条目附带图标，直接修改效果文字中的黄色数字，自动更新合计；初始值使用区间中点。数值限制在图鉴上下限内，越界输入结束时修正到边界；悬停数字可查看范围和默认值。固定数字不可修改，降序区间也支持。
4. 右侧查看方案合计；窄窗口向下滚动查看。选中攻速鞋后，在其卡片内填写假设移速，自动更新合计；留空则不估算该项加成。
5. 方案在当前应用或浏览器中自动保存，切页/重启后恢复；可移除条目或清空，清空可撤销一次。桌面和浏览器的本地存储不互通。

自由搭配不检查英雄适用、队伍唯一等抽选限制。合计只覆盖已支持的无条件效果，区分点数与百分比，是相加估算，不等于完整实战属性或最终乘区。未支持或需要触发/层数的效果列为未计入；固定值保留图鉴原文，不编造公式。

## 开发与验收

```powershell
npm install
npm run dev
```

浏览器预览：`npm run dev:web`，访问 http://127.0.0.1:5173 。模拟功能不依赖桌面接口。

验收：`npm run typecheck`、`npm test`、`npm run build`，网页服务运行时执行 `npm run test:ui`、`npm run test:reference` 和 `npm run test:privacy`。隐私检查扫描构建文件、六类资料界面、五个机制主题和复制文本，确保私人工程信息未混入，来源类展开内容、日期与提示段落均已删除。可通过环境变量 PLAYWRIGHT_CHANNEL=chrome 使用已安装 Chrome。原生检查为 `npm run test:electron`，请勿在对局时运行涉及窗口切换的原生测试。

打包：`npm run dist -- --config.directories.output=release/v1.0.0`，可追加 `--config.electronDist=node_modules/electron/dist` 复用本地 Electron。产物 `release/v1.0.0/Fuyou-Setup-1.0.0-x64.exe`。

旧版 GSI 和背包估算入口仍停用；新“局内”页使用独立悬停读数流程。此前用户安装的 GSI 配置未自动删除，新流程无需修改游戏启动参数。历史 capture-ui / overlay-ui 脚本仍为旧版参考，新专项验收运行 `npm run test:live`。

## 局内 buff 悬停读数（试用）

1. 进入“局内”→“开始采集”，选中自己的英雄，将鼠标停在技能栏上方的 buff 图标约 2–3 秒。默认每秒检查一次，鼠标需在下半屏；可暂停后取消位置限制。
2. 完整说明中的明确数值连续两次一致后入账，同名 buff 再次识别时覆盖更新，图标换位置不会重复相加。当前支持带可驱散／不可驱散说明的 buff 提示框，以及明确标签与百分号同一行的伤害增强、承伤、技能增强读数。
3. 明确写有“当前／总”的属性行按总值读取，其他数值先核对用途：角色总值直接显示，单项加成只作部分相加。总值与加成不混加；不一致的多个总值提示冲突。溢出攻速与下次攻击门槛是独立参考数值。
4. 点击“显示悬浮图标”打开圆钮，可拖动、展开、收起或关闭，与主窗口共享数据。暂停即释放识别进程；重启应用不恢复本局读数。
5. 超过 15 秒未读取、游戏切后台或暂停后显示上次读数。隐藏说明框不等于 buff 消失，失效项需设为“不计入”，换局请点“新局清空”。同名但不同来源的 buff、英雄是否为自己和换局均不能自动确认。

采集只读取前台 Dota 2 鼠标附近的有限画面区域，不操作游戏，不读内存，不保存或上传截图。推荐游戏无边框窗口模式。提供的“替身攻击”截图已完成本地 OCR 验证；伤害／承伤／技能增强目前通过合成用例验证解析，尚需实际提示框核对。未完成长期对局与 FPS 测试，不声称读取了未悬停的全部 buff。

已生成的数据和图标随仓库提供，普通开发与打包无需原始输入资料。可通过 FUYOU_SOURCE（清单与 CSV 目录）和 FUYOU_ICONS（PNG 目录）指定自备数据，输入文件约定见 docs/SPEC.md。

新增资料输出为 `data/reference.json`，显式重建使用 `npm run build:reference`，需在本机设置 FUYOU_REFERENCE_SOURCE（整合资料目录）、FUYOU_SOURCE（福佑基准目录）及 FUYOU_LOCALIZATION_SOURCE（游戏中文 KV 表 CSV）。构建产物仅保留游戏数据与日期，不包含私人输入目录或资料文件索引；界面不提供“查看来源”。构建校验 36 条符文中文名在提示标题与选择页中一致，并核对 69 池、125 英雄、113 有池、12 未配置、21 事件及两个缺失权重。原始 66 组池外的 3 组来自新 hero 表，不使用此前地址邻近的启发式映射。汉化专项验收为 `npm run test:localization`；其余浏览器检查可设置 TEST_SCREENSHOTS=0 仅运行断言，避免覆盖历史截图。

图标已保存于 `resources/runes`、`resources/heroes/icons` 和 `resources/heroes/portraits`，常规构建无需访问游戏文件。显式重新导入使用 `npm run import:reference-icons`，通过 FUYOU_HERO_VPK、FUYOU_RUNE_VPK 指定只读客户端与地图 VPK；不修改游戏。图标专项验收为 `npm run test:reference-icons`，检查全部图片加载、四种窗口尺寸和相关跳转。原图创作元数据已去除，文件仅携带公开游戏来源。

发布验证记录见 [docs/REPORT.md](docs/REPORT.md)。公开源码不包含本地截图验收材料。


### 队友红黑榜

队友 → 导入玩家／匹配截图 → 核对号码与昵称 → 选择红榜/黑榜并填写备注 → 保存。下次导入截图时按号码显示已有标记和备注，无后台采集。支持编辑、删除与搜索，仅本机保存。截图需清晰；完整名单识别不全时建议逐人裁剪。OCR 不可用时可手动填写。

记录文件位于 Electron 用户数据目录的 `teammate-roster.json`（默认 `%APPDATA%/fuyou-desktop/`），含截图缩略图。没有提取独立头像，也不查询 Steam 信息；请核对原图。公开源码不包含个人截图和私有截图验收材料。
